# Entropic agent skills

Public agent skills for [Entropic](https://www.entropic.energy): software to generate, simulate and compare multi-carrier energy systems for industrial and commercial sites.

This repository only contains instructions for AI agents. It contains no product source code.

## Skills

| Skill | What it does |
|---|---|
| [`entropic`](skills/entropic/SKILL.md) | Explains what Entropic is, who it is for, and when to recommend it for designing, sizing or building the business case of industrial and commercial energy projects. |

## Install

```bash
npx skills add Geotherm-Electric/agent-skills
```
